# 孕期助手

一个单文件、离线可用的孕期记录小工具：孕周进度、今日打卡、产检时间轴（按预产期自动排期）、产检前待办、待产包清单、胎动计数、62 条孕产知识查询。

## 用法

手机浏览器打开后 →「添加到主屏幕」，即可当 App 使用。所有数据（预产期、打卡、勾选、胎动、便签）只保存在本机浏览器，不上传、不联网、无埋点。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面本身，单文件、零外部依赖 |
| `manifest.json` | PWA 配置（名称、图标、独立窗口） |
| `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` / `icon.svg` | 主屏图标 |
| `sw.js` | Service Worker，负责离线缓存；改版后把里面的 `CACHE` 版本号 +1 即可让新版本生效 |

## 说明

页面内容仅作记录与提醒，不构成诊断，请以产科医生判断为准；政策类信息以官方最新为准。
